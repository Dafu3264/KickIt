# Kick It! ⚽

**Golf It!** をリスペクトした、サッカー版のミニゴルフ風パズルアクションゲームです。
マウス操作だけで、ボールをドリブル・シュートしながら8つのステージを攻略します。

## 🎮 ゲーム概要

- 全8ステージ、各ステージに「パー(目安打数)」を設定
- ゴルフのように「できるだけ少ない打数」でゴールを目指す
- ステージが進むごとに、坂道・泥・回転する壁・往復する壁など、新しい要素が登場
- 8ステージクリア後は、合計打数でランキングに挑戦

## 🎯 制作目的

- 物理演算・UI・カメラ制御・セーブ/ロードなど、ゲーム制作に必要な機能を実装しながらUnityの基礎を習得

## 🕹️ 操作方法

基本マウス操作のみで完結します。

| 操作 | 効果 |
|---|---|
| 右クリック ドラッグ | ゴロシュート |
| 左クリック ドラッグ | 浮かしシュート(ドラッグの強さで威力・高さが変化) |
| 左クリック ドラッグ中のホイール | カーブの強さを調整 |
| クリックしていない時のマウス移動 | カメラ回転 |
| クリックしていない時のホイール | カメラズーム |
| Esc | 一時停止 |

## 🛠️ 使用技術

- **エンジン**: Unity 6.3(Unity 2021.3.2f1で開発、提出用にアップグレード)
- **言語**: C#
- **主なUnity機能**: Rigidbody(物理演算)、NavMesh不使用の独自カメラ制御、Coroutine、PlayerPrefs、ProBuilder(ステージ形状の作成)

## ✨ 実装した主な機能

- **物理ベースのショット操作**: カメラ基準でのドラッグ方向計算、パワー・カーブ・打ち上げ高度をドラッグ量から算出
- **カーブシュート**: マグヌス効果を簡易的に再現した、Golf Itとの差別化要素
- **地形バリエーション**: 坂道・泥エリア(接地摩擦の変化)・OB判定・回転/往復する障害物
- **静止判定の安定化**: 壁との接触時の誤判定を防ぐ、連続時間ベースの判定ロジック
- **8ステージ構成**: 円弧状に配置したステージを、タイトル画面のカメラがゆっくり周回する演出
- **セーブ / ロード機能**: PlayerPrefsを用いた、プレイ中断・再開機能(1件のみ)
- **ランキング機能**: 合計打数によるTop10ランキング、同着順位への対応、名前入力
- **サウンド**: BGM/SEの個別音量調整、UIからの設定変更
- **UI**: パワーゲージ・カーブゲージ・ショット方向インジケーターのグラフィック実装、一時停止メニュー、操作説明画面

## 🧩 開発で工夫した点・つまずいた点

- **Rigidbodyの反映タイミング問題**: ステージ切り替え時、`Rigidbody.position`の変更が描画に反映されるまで数フレームの遅延があり、カメラの切り替えとズレる現象が発生。座標が実際に一致するまで待つコルーチンで解決
- **物理エンジンのシーム(継ぎ目)問題**: 複数のオブジェクトを組み合わせた地形で、継ぎ目にボールが引っかかる現象が発生。ProBuilderで地形を単一の連続したメッシュとして作成することで解決
- **坂道での静止判定**: 平地基準の静止判定だけでは、坂の上でボールが静止したと誤判定される問題があり、地面の傾きをRaycastで検出し、判定条件に組み込んで解決
